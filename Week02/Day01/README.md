**Technical concepts understood:**

- Asynchronous JavaScript allows operations to complete later without blocking the main thread while waiting.
- Promises represent the eventual success or failure of asynchronous operations.
- `resolve()` fulfills a Promise, while `reject()` rejects it.
- `.then()` and `.catch()` help handle Promise results and errors.
- The `async` keyword makes a function return a Promise.
- The `await` keyword pauses the current async function until a Promise settles.
- `fetch()` returns a Promise and is commonly used to retrieve data from APIs.
- `response.json()` returns a Promise that resolves to the parsed response data.
